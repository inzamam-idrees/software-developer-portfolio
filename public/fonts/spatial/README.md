# Spatial editorial font assets

Self-hosted Latin WOFF2, downloaded 2026-10-23 from Fontsource’s Google Fonts distribution:

- https://cdn.jsdelivr.net/fontsource/fonts/inter-tight:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/inter:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/jetbrains-mono:vf@latest/latin-wght-normal.woff2
- https://cdn.jsdelivr.net/fontsource/fonts/fraunces:vf@latest/latin-wght-italic.woff2

Existing cached FontTools restricts Inter Tight and Inter to weights 400–700, JetBrains Mono to 400–600, and Fraunces italic to 400–500. Each remains variable within its declared range. No package was installed. Upstream OFL licenses are included. Only Spatial preloads its critical Inter Tight/Inter faces; mono and serif load when used. All faces use font-display: swap. Space Grotesk and its unused license were removed for Phase 14; the Phase 13 working copy was backed up before editing.
